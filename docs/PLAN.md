# План пересборки

Авторизация: 2026-11-03, владелец попросил делать поэтапно, без участия у экрана.

1. Зафиксировать поведение и границы старой версии, подготовить отдельный проект.
2. Реализовать единое хранилище, строгий контракт понимания просьбы, независимый
   планировщик и квитанции подтверждений. Проверить реальные пользовательские сценарии
   на вымышленных данных.
3. Сделать нативный SwiftUI-интерфейс: Сегодня, Ассистент, Дела, Проекты;
   длинный ввод, редактирование плана, сохранение черновика, состояние связи.
4. Подключить отдельный сервер: долговечные задания, контролируемые вызовы DeepSeek,
   восстановление после обрыва и журнал результатов. Старый backend пока сохраняется.
5. Подготовить перенос из 25.3 без удаления исходных данных; Google — отдельная
   синхронизация со стабильными внешними ID и честным состоянием ошибок.
6. Собрать IPA по пути lumo: Xcode/GitHub Actions, чистый симулятор, реальные снимки.
   Сначала проверить доступ и бесплатный бюджет. Ничего не публиковать в lumo/fluxprod.
7. Проверить связанный сценарий, сохранить исходники, отчёт и точку продолжения.

## Критерии готовности

- Сумбурная диктовка с исправлениями превращается в цельный редактируемый план.
- Позднее исправление имеет приоритет; чужие обещания и уже сделанное не становятся делами.
- Неизвестная тема остаётся неизвестной; неизвестная длительность не выдаётся за факт.
- Дата без времени сохраняется как дата, не как встреча в полночь.
- Занятое время, длительности, перерывы, дедлайны и зависимости проверяются кодом.
- При недостатке времени незапланированное видно отдельно; ничего не теряется.
- Перенос меняет исходный ID и сохраняет длительность; фиксированные события защищены.
- После обычного вопроса старый план не исполняется.
- Повтор подтверждения/обрыв ответа/перезапуск не создаёт дублей.
- Ошибка сохранения не оставляет половину плана.
- Старые данные доступны через отдельный предварительный просмотр переноса.
- Нет обещания работы Google/ИИ без интернета или проверки реального iPhone в симуляторе.

## Решения

Упор на четыре понятных экрана. Графитовый фон, спокойные карточки, системный шрифт,
акцент цвета и настоящее системное стекло. Основной ввод — диктовка клавиатуры Apple,
не отдельная платная транскрибация. Никаких финансовых вычислений/экранов из lumo.
Используется только подход к нативной сборке. Старые защита от дублей, память и прогресс
рассматриваются как проверенные идеи, а не как обязательный код для копирования.
